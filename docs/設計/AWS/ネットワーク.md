# ネットワーク設計

## VPC 構成

```mermaid
graph TB
    subgraph "VPC (10.0.0.0/16)"
        subgraph "AZ-a"
            P1a["Private1<br/>(Isolated)<br/>/24"]
            P2a["Private2<br/>(Isolated)<br/>/24"]
        end
        subgraph "AZ-c"
            P1c["Private1<br/>(Isolated)<br/>/24"]
            P2c["Private2<br/>(Isolated)<br/>/24"]
        end

        subgraph "VPC Endpoints"
            VPCE_IF["Interface Endpoints<br/>(HTTPS 443)"]
            VPCE_GW["Gateway Endpoint"]
        end
    end

    VPCE_IF --- SSM["SSM"]
    VPCE_IF --- SECM["Secrets Manager"]
    VPCE_IF --- BRR["Bedrock Runtime"]
    VPCE_IF --- BRAR["Bedrock Agent Runtime"]
    VPCE_IF --- ECRA["ECR API"]
    VPCE_IF --- ECRD["ECR Docker"]
    VPCE_IF --- CWL["CloudWatch Logs"]
    VPCE_GW --- S3["S3 (無料)"]
```

- CIDR: `10.0.0.0/16`
- AZ 数: 2
- NAT Gateway: 0（Isolated サブネットのみのため不要）
- サブネット: `Private1`, `Private2`（共に `PRIVATE_ISOLATED`）
- prd 環境でも NAT なし → 全通信は VPC Endpoints 経由

## セキュリティグループ

```mermaid
graph LR
    subgraph "セキュリティグループ"
        SG_L["Lambda SG<br/>(Egress: ALL)"]
        SG_A["Aurora SG<br/>(Egress: NONE)"]
        SG_V["VPC Endpoint SG<br/>(Egress: ALL)"]
    end

    SG_L -->|"TCP 5432"| SG_A
    VPC_CIDR["VPC CIDR<br/>10.0.0.0/16"] -->|"TCP 443"| SG_V
```

| SG | Inbound | Outbound | 用途 |
|---|---|---|---|
| Lambda SG | - | ALL | Lambda / AgentCore 用 |
| Aurora SG | Lambda SG → TCP 5432 | なし | Aurora クラスター用 |
| VPC Endpoint SG | VPC CIDR → TCP 443 | ALL | VPC Endpoints 用 |

## VPC Endpoints 一覧

| エンドポイント | タイプ | 用途 |
|---|---|---|
| SSM | Interface | Systems Manager パラメータ |
| Secrets Manager | Interface | DB 認証情報取得 |
| Bedrock Runtime | Interface | LLM / Embedding 呼び出し |
| Bedrock Agent Runtime | Interface | Rerank API |
| ECR API | Interface | AgentCore コンテナイメージ取得 |
| ECR Docker | Interface | AgentCore コンテナイメージ取得 |
| CloudWatch Logs | Interface | AgentCore ログ出力 |
| S3 | Gateway | ECR レイヤーキャッシュ等（無料） |

全 Interface Endpoint は Private DNS 有効、`Private1` サブネットに配置。
