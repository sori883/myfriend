# 2. 中期記憶（Observations）

蓄積された Raw Facts を自動統合し、パターン検出・鮮度追跡を行う。グラフ検索で記憶間の関係をたどる。

## 2.1 ローカルインフラ

### 2.1.1 DB マイグレーション（中期記憶テーブル） ✅

- テーブル: `memory_links`, `entity_cooccurrences`, `async_operations`
- インデックス: HNSW パーシャル, B-tree グラフトラバーサル, GIN タグ等

### 2.1.2 ローカル Consolidation スケジューラー ✅

- asyncio ベースの定期実行スケジューラー（5分間隔）
- 手動トリガー用の CLI コマンド

---

## 2.2 アプリケーション — Consolidation

### 2.2.1 Consolidation Worker コアロジック ✅

- 未統合 Fact 取得 → 関連 Observation 検索 → LLM 判定
- 4パターン: REDUNDANT / CONTRADICTION / UPDATE / NEW
- 異なる人物の事実をマージしない等の制約

### 2.2.2 鮮度追跡 ✅

- 鮮度計算: 直近30日 vs それ以前の証拠密度比
- ステータス: STRENGTHENING / WEAKENING / STABLE / NEW / STALE

---

## 2.3 アプリケーション — グラフ

### 2.3.1 グラフリンク構築 ✅

- 4種のリンク自動作成: temporal, semantic, entity, causes/caused_by
- エンティティ共起頻度の更新

### 2.3.2 MPFP グラフ検索 ✅

- ホップ同期トラバーサル（LATERAL JOIN）
- 7つのメタパスパターン

### 2.3.3 時間検索 ✅

- 直接時間範囲マッチ + リンク通じた拡散伝播

---

## 2.4 アプリケーション — 検索強化

### 2.4.1 4方向並列検索統合 ✅

- `asyncio.gather` で4方向並列検索（セマンティック、BM25、グラフ、時間）
- 検索優先度: Observations → Raw Facts

### 2.4.2 クロスエンコーダリランキング ✅

- Bedrock Rerank API で top-300 リランキング
- 最終スコア: 0.5*CE + 0.3*RRF + 0.1*recency + 0.1*temporal

### 2.4.3 バッチクエリ最適化 ✅

- WINDOW 関数で複数 fact_type 検索を1クエリに統合

## 2.6 アプリケーション — エンティティ解決の強化 ✅

### 2.6.1 共起エンティティスコアリング ✅

- Retain 時に `entity_cooccurrences` テーブルを更新
- 共起スコア計算（overlap / len(nearby_entities) × 0.3）

### 2.6.2 時間的近接性スコアリング ✅

- 7日以内で高スコア: `max(0, 1.0 - (days_diff / 7))` × 0.2

### 2.6.3 エンティティ解決のバッチ処理 ✅

- 全候補・全共起を1クエリで一括取得
- DB クエリ数がエンティティ数に依存しない
