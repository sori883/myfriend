# 10. 外部検索連携

嗜好データ × Web 検索で、実在するイベント・店舗・コンテンツをユーザーに提案する。

設計: [docs/設計/レコメンデーション/レコメンデーションエンジン.md](../設計/レコメンデーション/レコメンデーションエンジン.md) 10節

## 10.1 web_search モジュール ✅

### 10.1.1 Tavily API クライアント実装 ✅

- `recommendation/src/recommendation/web_search.py` を新規作成
- Tavily API を使用した検索クライアント（`asyncio.to_thread` で同期 SDK をラップ）
- レスポンス: `{results: [{title, snippet, url}], query}`
- API キーは環境変数 `TAVILY_API_KEY` から取得（未設定時は `RuntimeError`）
- クエリ正規化・防御的レスポンス整形・Tavily API エラーハンドリング実装済み

### 10.1.2 ツール定義 ✅

- `agentcore/core.py` に `web_search` ツールを追加
- `query`（必須）を引数に取る
- 空チェック・長さバリデーション・`TAVILY_API_KEY` 未設定時のエラーハンドリング

### 10.1.3 System Prompt 更新 ✅

- web_search ツールの使い方を System Prompt に追記
- 検索前に get_user_profile / recall_memories で好みと場所を確認する旨を記載
- 検索クエリには具体的な地名・時期・キーワードを含める旨を記載
- 検索結果をそのまま列挙しない、自然に紹介する旨を記載

---

## 10.2 レート制限 ✅

### 10.2.1 SearchRateLimiter 実装 ✅

- `web_search.py` に `SearchRateLimiter` クラスを実装
- 1会話あたり最大 3 回、1日あたり最大 20 回（bank 単位）、最小検索間隔 10 秒
- 制限到達時はエラーメッセージと残り回数を返す
- `asyncio.Lock` による並行アクセス保護

---

## 10.3 検索結果キャッシュ ✅

### 10.3.1 インメモリキャッシュ実装 ✅

- 同一クエリの重複検索を防止（クエリ正規化: strip + lower）
- TTL: 15 分、サイズ上限: 100 件（LRU 風の古いエントリ自動削除）
- TTL 超過分はアクセス時に自動削除
- キャッシュチェックはレート制限チェックの前（キャッシュヒット時はレート制限を消費しない）
