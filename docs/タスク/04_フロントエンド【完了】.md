# 4. フロントエンド（aituber-kit ベース）

aituber-kit をフォークして `front/` に配置し、3D/2Dアバター付きのリッチなチャットUIを実現する。
バックエンド (`agentcore/local.py`) は変更せず、フロント側のプロキシAPIでレスポンス形式を吸収する。

## 4.1 プロジェクトセットアップ

### 4.1.1 aituber-kit クローン & 初期構成 ✅

- `front/` に aituber-kit をクローン（git history 不要）
- `pnpm install`、`.env.local` 設定
- `next.config.js` に `eslint.ignoreDuringBuilds: true` 追加

---

## 4.2 AgentCore バックエンド統合

### 4.2.1 プロキシAPIルート作成 ✅

- Next.js API Route でリクエストを AgentCore に中継
- bank_id の UUID バリデーション、エラーサニタイズ

### 4.2.2 チャットサービス追加 ✅

- `agentCoreChat.ts`: `/api/ai/agentcore` を呼び出すチャットサービス
- `aiChatFactory.ts` に `"agentcore"` ケースを追加

### 4.2.3 Settings Store 拡張 ✅

- `agentcoreBankId` フィールド追加
- `aiService` のデフォルトを `"agentcore"` に変更

---

## 4.3 デフォルト設定 & 初期構成

### 4.3.1 環境変数 & デフォルト設定 ✅

- `AGENTCORE_URL`（サーバーサイド）、`NEXT_PUBLIC_AGENTCORE_BANK_ID` 設定

### 4.3.2 設定画面に AgentCore 項目追加 ✅

- AI サービス選択肢に "AgentCore" を追加（リスト先頭）
- Bank ID 入力フィールド
- AgentCore 選択時は不要な設定を非表示

---
