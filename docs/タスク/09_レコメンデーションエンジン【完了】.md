# 09. レコメンデーションエンジン

嗜好プロファイルを活用し、スコアリング・多様性制御・フィードバックループによるパーソナライズされた提案を行う。

設計: [docs/設計/レコメンデーション/レコメンデーションエンジン.md](../設計/レコメンデーション/レコメンデーションエンジン.md)

- インデックス: `(bank_id, entity_id, category)`, `(bank_id, entity_id, created_at DESC)`

---

## 09.2 レコメンデーションロジック ✅

### 09.2.1 スコア計算 ✅

- `recommendation/src/recommendation/recommendation.py` を新規作成
- スコア計算: `score = intensity * 0.5 + evidence_bonus * 0.3 + recency_bonus * 0.2`
- `evidence_bonus`: `min(evidence_count / 10, 1.0)`
- `recency_bonus`: 最終言及からの経過日数に応じて減衰（7日以内: 1.0, 30日以内: 0.7, 90日以内: 0.4, それ以上: 0.2）

### 09.2.2 フィルタリング ✅

- `sentiment = 'negative'` → 回避リストへ（最大10件）
- `sentiment = 'neutral'` → 推薦候補（低スコア）
- `sentiment = 'positive'` → 推薦候補

### 09.2.3 多様性制御 ✅

- 直近7日間の推薦履歴を取得（`unnest` で配列展開）
- スコア減衰: 24時間以内 ×0.1、3日以内 ×0.3、7日以内 ×0.6、7日以上前 ×1.0
- 同じアイテムの繰り返し推薦を防止

### 09.2.4 上位N件選出・回避リスト生成 ✅

- スコア降順で上位3件を返す
- `sentiment = 'negative'` のアイテムを回避リストとして返す

### 09.2.5 推薦履歴記録 ✅

- 推薦結果を `recommendation_history` に INSERT（ID を返す）
- 嗜好データが0件の場合は空の推薦結果とメッセージを返す
- 履歴記録失敗時は警告ログのみ（推薦自体は返す）

## 09.3 recommend ツール ✅

### 09.3.1 ツール定義 ✅

- `agentcore/core.py` に `recommend` ツールを追加
- `category`（必須）と `context`（省略可）を引数に取る
- `ALLOWED_CATEGORIES` でカテゴリバリデーション
- `preference_engine.recommend()` を呼び出して結果を返す

### 09.3.2 System Prompt 更新 ✅

- recommend ツールの使い方を System Prompt に追記
- 結果をそのまま列挙しない、自然な会話として提案する旨を記載
- 推薦頻度の制限ガイドを追記
- record_recommendation_feedback の使い方を追記
- 絶対ルールにリスト読み上げ禁止を追加
