# 3. 長期記憶（Mental Models）

キュレーション済みサマリとして最高信頼度の知識を管理し、深い推論（Reflect）を実現する。

## 3.1 ローカルインフラ

### 3.1.1 DB マイグレーション（長期記憶テーブル） ✅

- テーブル: `mental_models`, `chunks`
- インデックス: HNSW, B-tree

---

## 3.2 アプリケーション

### 3.2.1 Mental Model CRUD ✅

- Create / Read / Update / Delete
- `refresh_after_consolidation` / `is_stale` フラグ管理

### 3.2.2 Mental Model 自動リフレッシュ ✅

- Consolidation 完了後にタグ重複する Mental Model をリフレッシュ
- 関連 Observations 収集 → LLM でサマリ再生成

### 3.2.3 Reflect パイプライン ✅

- エージェントループ（最大10イテレーション）
- 5つのツール: search_mental_models, search_observations, recall, expand, done
- 証拠ガードレール、ID 検証（ハルシネーション防止）

### 3.2.4 Disposition（性格特性）適用 ✅

- 3軸の性格特性（skepticism, literalism, empathy、各 1-5）
- Reflect 時のプロンプトに注入

### 3.2.5 ディレクティブシステム ✅

- `banks` テーブルの `directives` から読み込み
- Reflect 時にハードルールとして注入

### 3.2.6 Strands Agent Reflect ツール統合 ✅

- `@tool reflect_on`: トピックについて深く推論

---

## 3.3 アプリケーション強化

### 3.3.1 並行制御 ✅

- セマフォ設定: search=32, put=5, llm=32

### 3.3.2 タグベース可視性制御 ✅

- 4つのフィルタモード: any, all, any_strict, all_strict
