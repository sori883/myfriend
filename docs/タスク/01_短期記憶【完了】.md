# 1. 短期記憶（Raw Facts）

会話から5W1H構造の事実を抽出し、Embedding付きで永続化する。基本的な Retain/Recall を実現する。

## 1.1 ローカルインフラ

### 1.1.1 Docker PostgreSQL 環境の拡張 ✅

- 既存の `pgvector/pgvector:pg16` ベースを活用
- Apache AGE（グラフDB拡張）をソースからビルド
- pg_bigm（日本語 bi-gram 全文検索）をソースからビルド
- `pg_trgm` エクステンション有効化
- ヘルスチェック追加

### 1.1.2 DB マイグレーション（短期記憶テーブル） ✅

- エクステンション: vector, pg_trgm, pg_bigm
- テーブル: `banks`, `documents`, `memory_units`, `entities`, `unit_entities`
- インデックス: HNSW, GIN (pg_bigm), B-tree
- トリガー: `updated_at` 自動更新

### 1.1.3 Python DB 接続設定 ✅

- asyncpg ベースの接続プール管理
- pgvector 型登録
- `.env` から `DATABASE_URL` を読み込み

---

## 1.2 アプリケーション

### 1.2.1 Memory Engine コアモジュール ✅

- `MemoryEngine` クラス（DB 接続プール管理）
- `retain()` / `recall()` の公開インターフェース

### 1.2.2 LLM ファクト抽出 ✅

- Bedrock Converse API（Claude Haiku）でファクト抽出
- 入力テキスト → 2〜5個のナラティブ事実
- 5W1H 構造、時間表現の正規化、`fact_kind` / `fact_type` 分類

### 1.2.3 Embedding 生成 ✅

- Bedrock Titan Embed V2（1024次元）でベクトル生成
- バッチ対応

### 1.2.4 エンティティ抽出・解決 ✅

- エンティティ解決スコアリング（名前類似度 0-0.5、共起エンティティ 0-0.3、時間的近接性 0-0.2）
- 統一しきい値: 0.6

### 1.2.5 Retain パイプライン ✅

- LLM ファクト抽出 → Embedding 生成 → 重複チェック → DB トランザクション
- 重複検出: 12時間バケット + コサイン類似度

### 1.2.6 Recall パイプライン（基本版） ✅

- 2方向検索: セマンティック検索 + 全文検索（pg_bigm）
- RRF 融合、トークンバジェット管理

### 1.2.7 Strands Agent ツール統合 ✅

- 共通ロジックを `core.py` に集約
- `@tool remember` / `@tool recall_memories`
- `main.py`（AgentCore 用）、`local.py`（ローカル開発用）
